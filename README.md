# Sande Kokuyo – Berichtsheft

Das Berichtsheft von Sande Kokuyo für das Naruto-RP: Missionen, Training, Kämpfe und Dienst mit Wochenübersicht,
Chakra-Kalender, Missionsrängen, Suche und Druckansicht.

## Online stellen (GitHub Pages)

1. Auf GitHub ein neues **öffentliches** Repository namens `sande-kokuyo-berichtsheft` anlegen.
2. Diesen Ordner hochladen (oder per `git push`).
3. Im Repository: **Settings → Pages → Branch: `main` / `(root)` → Save**.
4. Nach ein bis zwei Minuten ist das Heft erreichbar unter
   `https://<dein-github-name>.github.io/sande-kokuyo-berichtsheft/`.

## Einträge schreiben

1. Unten auf der Seite **Schreibmodus** einschalten (oder `#schreiben` an die Adresse hängen).
2. **✎ Neuer Eintrag** → ausfüllen → **Abstempeln**. Der Eintrag ist jetzt nur in deinem Browser gespeichert.
3. **⇩ Für GitHub exportieren** lädt eine neue `eintraege.js` herunter.
4. Auf GitHub `eintraege.js` durch die heruntergeladene Datei ersetzen (Datei öffnen → Stift → Inhalt ersetzen →
   *Commit changes*). Danach sehen alle anderen die neuen Einträge.

Steckbrief, Herkunft und Ziele stehen oben in `eintraege.js` unter `PROFIL`. Uhrzeiten (`von`/`bis`) sind optional,
`"meilenstein": true` hebt einen Eintrag golden hervor. Jeder RP-Abend (jedes Datum) zählt in der Geschichte als ein
Monat. Die Monate werden automatisch durchgezählt, echte Daten zeigt die Seite nicht an.
